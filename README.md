# 💱 Conversor de Moedas

Um projeto moderno de conversão de moedas desenvolvido com HTML, CSS e JavaScript, consumindo uma API de câmbio em tempo real.

## 🚀 Funcionalidades

* Conversão entre moedas em tempo real
* Atualização automática utilizando API
* Conversão ao clicar no botão ou apertar Enter
* Troca dinâmica de bandeiras, nomes e símbolos das moedas
* Interface moderna e responsiva
* Layout inspirado em aplicativos financeiros

## 💵 Moedas disponíveis

* 🇧🇷 Real Brasileiro (BRL)
* 🇺🇸 Dólar Americano (USD)
* 🇪🇺 Euro (EUR)
* 🇬🇧 Libra Esterlina (GBP)
* 🇦🇷 Peso Argentino (ARS)

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Exchange Rate API

## 📷 Preview

Projeto desenvolvido com foco em prática de JavaScript, consumo de API, manipulação do DOM e responsividade.
